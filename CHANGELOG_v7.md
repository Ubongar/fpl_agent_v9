# Change history

The repository retains the historical v7 filename for compatibility, but the current release is v9.1.

## v9.1
- Added transparent probabilistic decision metrics instead of a single opaque player score.
- Added first-class Player Compare workspace with 2–8 players, reference deltas, metric lenses and pairwise simulation.
- Added Player Lab comparison tray and Player X-ray comparison actions.
- Added Command Center, Fixture Lab, Market Watch, Model Lab and My Team workflows.
- Added same-origin Next.js API proxy with server-side API key handling.
- Corrected minutes modelling into play/start/60+ events.
- Corrected legal squad geometry, simulation event conservation, transfer handling and point-in-time protections.
- Corrected penalty-goal BPS and ownership fallback behaviour.
- Added regression tests and release hygiene checks.
